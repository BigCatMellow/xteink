# XTEINK projects

Projects and experiments for the XTEINK X4 Pro, primarily running XTOS Licorice.

## Games

- [Paper Golf](paper-golf/README.md) — monochrome stroke-limited golf-puzzle game.
- [Summit Putt](summit-putt/README.md) — card-based golf routing puzzles with finite cards and ramps.
- [Line Lift](line-lift/README.md) — zero-animation black-and-white crossing-logic puzzles inspired by Hook.
- [Link Grid](link-grid/README.md) — **zero-animation** tile rotation and line-connection puzzles with 20 uniquely solvable levels.

## Utilities

- [Wallpaper Randomizer](wallpaper-randomizer/README.md) — rotates lock-screen JPEGs without an immediate repeat.
