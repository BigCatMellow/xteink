remains [xteink AGENTS](../../../AGENTS.md) and the user's requested scope.

filesystem layout are not imported.

question. This index owns method routing only. Source receipts and terminology

Method-only application is appropriate here: no SQLite/LangGraph/hcom installation,
daemon, knowledge graph, ProjectUpdater installation or automated promotion is
needed for this research/planning result. If future execution requires stronger
machinery, justify it against a concrete failure mode first.

At each meaningful work-arc close, review open observations and proposed ideas:
promote within authority, mark stale/killed with lineage, or incubate with reason.
Three consecutive incubations without movement require operator attention under
the upstream emergence method. Do not hide unresolved captures in an archive.
