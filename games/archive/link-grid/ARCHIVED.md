# Link Grid — archived 2026-11-14

**Reason:** An independent local edge-consistency analysis of its existing 20 board definitions resolved all tiles without branching, in 1–3 constraint-propagation passes. Several puzzles begin with over half the tiles immediately determined by boundary or fixed-anchor rules. This establishes a shallow local-inference design; it is not a claim that every player solves them instantly.

**Reactivation:** Authored boards should need linked nonlocal deductions, plausible alternatives and long dependencies even at 480×800. Retest uniqueness, measure actual reasoning depth, and playtest without hints.

Original app, manifest, tests, artwork, icon (now `icon.svg`) and former workflow (`build-workflow.yml`) remain here. Historic releases and player saves are unchanged.
