# margin-codex — parked prototype (2026-11-14)

**Why held:** The 16-page browser trial has an appropriate e-ink interface, but many of its puzzles use short, recognizable, single-stage ciphers or indexing. Recognition is too often the whole solution; it needs multi-layer and interacting clues before becoming an active game.

This is the preserved original HTML proof of concept and its existing design documentation/tests, not a native XTOS game and not an active Games Hub app. No physical device install, user save deletion, or release took place.

**Return bar:** three original, genuinely challenging levels requiring multiple connected deductions or consequential planning; clear no-guess rules; 480×800 monochrome readable pages and large controls; independent solution validation plus real playtesting. Only after that should a native Lua app be proposed through the full game quality and installation pipeline.
