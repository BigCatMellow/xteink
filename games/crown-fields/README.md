# Crown Fields

Original monochrome Crowns/Queens logic. Place exactly one crown in each row, column and outlined region; crowns never touch, including diagonally. Select Crown or X, then tap. Tap the same mark again to clear. Check submits; undo and reset are separate. Help contains optional automatic exclusion dots (visual only; they never modify saves).

20 original levels: four each of 5×5 through 9×9. The original first 12 boards, app ID and v1 saves are preserved; completed level 12 unlocks level 13. Eight new layouts have connected regions, a unique solution and no singleton regions. Search counts are not human difficulty ratings.

Shared UI/theme, near-full-width board, strong region outlines, no redundant region letters, static monochrome screen. Run the repository quality gate and inspect before/after bitmap previews before release. Physical reader review remains required.
