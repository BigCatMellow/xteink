# Crown Fields — device acceptance
1. Install in Licorice from **SD:/Apps/**; do not remove **XTApps/**.
2. Verify region letters, heavy region borders, X marks and crown symbols on all 5×5–7×7 layouts at actual 480×800.
3. A cell cycles blank/X/crown/blank with one static redraw per tap.
4. CHECK must reject incomplete arrangements. A complete correct grid before CHECK must remain saved but unsubmitted across app relaunch.
5. Verify thick boundary regions and crown symbols are distinguishable without color or gray.
6. Test UNDO, RESET, PREV/NEXT, previous and new unlocks, and physical side buttons.
7. Leave an incomplete level, visit another, reopen, return; no marks or undo history should be lost.
8. Test help screen, sleep and wake, and no periodic updates. CI does not establish these hardware properties.
