# Akari (Lantern Logic)

Original Light Up puzzles, 28 fixed original levels: the previous 16 at 5×5–7×7 and twelve new 8×8–10×10 boards. The existing app ID lanternlogic, original level data, v1 save records and per-level undo history are retained. No new duplicate app is installed.

Select Bulb or X then tap a white cell. Tap the same mark to clear. Light every white cell; bulbs cannot see one another; numbered walls require that many orthogonal bulbs. Dots mark lit cells, brackets mark conflicts. Help contains full rules; progress status and mark modes are close to the near-full-width grid. Correct boards unlock the next level automatically. No animation/network/color dependency.

New boards are generated offline and checked by deterministic constraint propagation. The independent Python solver counts solutions up to two. Challenge estimates are not physical-device or human-rated difficulty evidence. Use the quality gate and inspect actual shipped-font previews before release.
