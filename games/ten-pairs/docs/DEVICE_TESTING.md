# Ten Pairs — device acceptance
1. Install from **SD:/Apps/**; open Ink App → Ten Pairs.
2. Verify all 8 columns of numbers and up to 11 rows remain legible at normal and large font settings.
3. Match identical digits and digits summing to 10, including pairs separated by crossed-off spaces, vertical/diagonal lines and reading-order row wraps.
4. An invalid pair must not remove either digit.
5. ADD must copy remaining numbers in reading order to the bottom, never animate them. A full sheet must refuse extra rows.
6. Use HINT twice on one sheet, confirm rings show a legal pair. UNDO restores the previous state.
7. Save an expanded sheet with a selected digit, quit and reopen; both must persist.
8. Finish a board, unlock the next, revisit the old board. Test physical page buttons and sleep.
9. Confirm no fading, animation, sound or periodic refresh.
