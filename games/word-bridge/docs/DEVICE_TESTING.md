# Word Bridge — physical X4 Pro acceptance

1. Install `word-bridge.xtapp` from **SD:/Apps/** without uninstalling prior app data in firmware-managed **XTApps/**.
2. Confirm the 480×800 portrait screen shows twelve readable word cards, NOW/GOAL, move counter, and bottom controls.
3. Tap a word differing from the current word by one letter: it should advance the chain with one static redraw. A two-letter difference should not advance it.
4. Check eligible-word circles and already-used cards remain visible. Re-selecting used cards must not add moves.
5. Use a wrong first-turn branch and run out of moves. Undo back to a valid route.
6. Use HINT once to mark a next word and confirm it cannot be consumed twice.
7. Exit after selecting two words, reopen, then confirm the same chain and hint state return.
8. Finish level 1 within budget, unlock level 2 and revisit level 1 without losing its winning path.
9. Test a 7-move puzzle and the Help screen for legibility.
10. Verify physical page buttons navigate stages only and don't select cards.
11. Leave idle and test sleep/wake: no animation or background refresh.

The automated suite cannot establish physical touch alignment, font rendering, or sleep behavior.
