# Oddity Hunt — physical X4 Pro acceptance checklist

1. Install `oddity-hunt.xtapp` over the existing copy, if any, from **SD:/Apps/** using All Files, leaving **XTApps/** to the firmware.
2. Open Ink App → Oddity Hunt. Confirm title, scene label, shelf illustration, five target labels, counters and bottom controls all fit on the 480×800 portrait screen.
3. Inspect the drawings at actual size. Each target must be distinguishable, the linework crisp and dense enough to feel like a search game, without text overlay or unreadable symbols.
4. Tap a correct item. Its picture should immediately gain a static circle; the corresponding checklist item should get a check mark. No movement or intermediate frames.
5. Tap a decoy; check a miss is counted but the shelf stays unchanged.
6. Tap blank shelf space, then tap an already-found object: neither should add a find or a miss.
7. Use HINT: verify a double ring highlights one specific missing object; tapping HINT again should not consume another hint until that object is found.
8. Find that object, then use HINT again. A third new hint must be unavailable on that shelf.
9. Complete the five-object checklist. NEXT unlocks the following scene; the previous scene stays completed.
10. Partially complete scene 2, close the app, reopen, return to scene 1 and then scene 2. Both scenes should preserve found objects, hints and misses.
11. RETRY only resets the active scene without losing any prior unlocks.
12. Try the physical previous/next page buttons and confirm neither selects a picture.
13. Check the help screen and back button at both normal and larger display fonts, if supported.
14. Play through all 12 scenes. Confirm final completion survives sleep, wake and an app relaunch.
15. Leave the screen idle. There must be no periodic refreshes, animation or sound.

The app is **not device-verified** until these checks pass on real X4 Pro hardware.
