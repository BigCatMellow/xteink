# Sum Cross — physical X4 Pro tests
1. Install from SD:/Apps/ and launch from Ink App.
2. Check black clue cells in 5×5–7×7 boards. The top-right DOWN sum and lower-left ACROSS sum must be individually legible.
3. Tap a white cell, then press a digit 1–9. Only the selected square changes, in one static redraw.
4. CLR clears the selected digit; UNDO restores it. Tap a filled clue cell: no digit should enter it.
5. CHECK with missing or incorrect sums must leave grid editable.
6. Fill a correct grid, leave without CHECK, reopen and ensure it remains unsubmitted; then CHECK to unlock the next level.
7. Test saved selections, partially filled grids, visits between stages and retained undo history.
8. Verify keypad hitboxes, physical side buttons, help, sleep and wake; no animation or periodic refresh.
