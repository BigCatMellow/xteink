# Word Hunt — physical X4 Pro test

1. Install the XTApp from **SD:/Apps/** using All Files, leaving existing **XTApps/** data intact.
2. Launch and confirm header, WORDS/FOX selector, 8×8 word grid, list of four words, status and buttons are readable in 480×800 portrait.
3. Tap first and last letters of a listed word. Verify both forward and reverse endpoints are accepted; the letters receive static circles and the word receives a check.
4. Tap two unrelated letters; no word should be credited. Tap the same starting letter twice to cancel selection.
5. Complete a 4-word board, unlock NEXT, and return to ensure previous finds remain marked.
6. Use HINT twice (one target at a time). The next unused hint must not be available until the marked word is found.
7. Switch to FOX mode. Confirm a 13×13 grid contains only F/O/X, no colored artwork, and a single FOX can be found with two taps.
8. Check both diagonal and backward FOXs in later stages; tapping the ending X first should work too.
9. Switch between modes and reopen the app; unlocked levels, found words, and used hints should remain separate and intact.
10. RESET on one grid must not clear progress on others. Physical page buttons navigate only.
11. Check a long word in an 8×8 grid, help screen, all four bottom controls, and highlighted letters for alignment and ghosting.
12. Leave idle; there should be no animation or periodic redraw.
13. Upgrade from v0.1.1 with unfinished searches in both modes; finds, hints and unlocks must remain. Complete each mode's eighth puzzle and verify NEXT generates puzzle 9.
14. Start a generated grid, find one word, use a hint, visit an earlier puzzle and relaunch. Return to the exact same grid, find count and hint state. Record generation time for WORDS and FOX.

CI validates uniqueness and host rendering but cannot substitute for this device check.
